## 1. 번호와 분류 규칙

- **DEF-1 ~ DEF-7**: 공개 저장소의 번호를 그대로 씁니다(ISS). 같은 결함에 번호를 두 개 만들지 않기 위해서입니다.
- **DEF-20부터**: 이 문서에서 새로 등록한 것입니다. DEF-8 ~ DEF-19는 비워 둡니다. 팀 `capstone_hils` 기록이 DEF-10, DEF-16~18을 다른 뜻으로 쓰기 때문입니다(`src/capstone_hils_20261028/오늘작업_요약_20261028.md:4,57`).
- **TI-n**: 측정·시험 도구 결함입니다. TI-1, TI-2는 ISS 번호와 같습니다(이 문서에서는 TI-01, TI-02로 적습니다).
- **ENV-n**: 시험 환경 문제입니다. 결함으로 세지 않고 위험으로 관리합니다(`man3_plan.md` 위험 등록부).

- 종결 = 수정 + 수정 전 코드에서 실패하는 회귀 시험 또는 보드 회귀 랩 통과
- 미해결(코드 수정, 보드 미검증) = 코드는 고쳤지만 보드에서 돌지 않음. 닫지 않음

- 수용(한계) = 고치지 않고 한계로 보고하기로 기록된 것
