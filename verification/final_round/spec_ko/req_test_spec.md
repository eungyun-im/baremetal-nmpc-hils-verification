# 요구사항과 테스트 케이스 명세 (v0.3)

이 문서가 과제의 **주 요구사항 명세**다. 현업 검증 전문가의 조언에 따라 요구사항을 **기능, 비기능, 기능안전** 세 분류 16개(기능 4, 비기능 5, 기능안전 7)로 정하고, 요구사항마다 기준, 테스트 케이스, 표본 수를 정한다.

- 상세 요구사항 57개([`swe1_requirements.md`](swe1_requirements.md))는 코드에서 거꾸로 도출한 근거 목록이다. 이 문서의 요구사항이 어느 코드와 상세 항목에 걸리는지 보여 줄 때만 인용한다.
- 판정 수치의 정본은 [`../acceptance_criteria.md`](../acceptance_criteria.md)와 `bmpc_bridge/config/acceptance.json`이다.

## 0. 작성 순서 (사실 그대로)

- 원래 순서는 "요구사항 → 합격 기준 → 테스트 케이스 → 실행"이다. 이 과제는 처음 기준(AC-01~10, 결함 주입)만 2026-11-05에 정하고 시험을 시작했다.
- 2026-11-11에 추가한 기준(AC-11, AC-22, `solve_fail`)과 AC-04 정의 변경은 **기존 기록을 본 뒤에 정했다.** 변경 이력에 그렇게 적었다.
- **최종 측정(새 펌웨어로 하는 TC-H01, TC-H11~H18, TC-S02, TC-N01, TC-D01) 전에 이 문서(v0.3)의 기준과 랩 수를 확정했다(2026-11-11, 계획 파일 `bmpc_bridge/scripts/laps_plan_final3.json`, md5 `db4e4aa71bfb55b11e7e38331fcd2ec5`).** 최종 결과를 보고 기준이나 랩 수를 바꾸지 않는다. 바꿔야 하면 변경 이력에 이유와 영향을 적고, 바꾸기 전 판정도 함께 보고한다.
- 원본 NMPC 시범 1랩(`bags/test_runner/nmpc_smoke_20261111`)은 실행 확인용이며 집계하지 않는다.

## 4. 표본과 말할 수 있는 범위

모든 시도가 성공했을 때 실패율의 95 % 상한은 약 3/n이다(rule of three).

| 주장 | 표본 | 결과 | 말할 수 있는 것 | 말할 수 없는 것 |
|---|---|---|---|---|
| 짧은 솔버 실패(≤ 100 ms)에서 정지하지 않는다 | 호스트 1,210회 | 1,210 통과 | 이 로직의 실패율 < 약 0.25 % | 보드 타이밍에서의 비율 |
| 긴 솔버 실패(≥ 300 ms)에서 290 ms 안에 정지한다 | 호스트 1,938회 | 1,938 통과, 정지 시간 항상 150 ms | 로직의 실패율 < 약 0.15 %. 정지 시간은 위상과 무관하게 명령 시간 초과(200 ms) − 한 주기(50 ms) | 보드에서 같은 시간이 나오는지 (TC-H14) |
| 명령 두절에서 같은 기준을 지킨다 | 호스트 짧음 1,501 / 김 2,500회 | 모두 통과 | 실패율 < 약 0.2 % / 0.12 % | – |
| 결함이 없으면 정지하지 않는다 | 호스트 1,000회(약 10만 주기), HILS 무결함 175랩(이전) + 20랩(새) | 이전 0건, 새 펌웨어 진행 전 | 오검출 확률이 낮다는 근거 | 장시간 운행의 오검출률 |
| 보드에서 솔버 실패 대응이 동작한다 | HILS 10회 (위치 10곳) + 짧은 실패 4회 | 진행 전 | 통합(보드, CAN, 타이밍)이 맞물려 동작함 | 신뢰도 수치. 10회 모두 성공해도 실패율 95 % 상한은 약 30 % (3/n 근사, 정확히는 1 − 0.05^(1/10) = 26 %) |
| 기존 결함 대응이 새 펌웨어에서도 동작한다 | HILS 15랩 (결함 6종) | 진행 전 | 수정(SWR-45)이 다른 안전 경로를 깨지 않았다는 회귀 확인 | 결함별 신뢰도 |
| MCU 제어가 원본 NMPC와 같은 추종 성능을 낸다 | HILS 20 대 원본 NMPC 20랩 (블록 교차) | 진행 전 | 랩 간 편차 수준에서 차이가 없다 | 동등성 증명(TOST 아님) |
| 한 주기가 50 ms 안에 끝난다 | HILS 약 76,000 주기 + 벤치 16,576 요청 | 진행 전 / 벤치 통과 | 측정 분포와 최대값, 기준까지의 여유 | WCET. 최대값은 표본 수와 상관없이 상한이 아니다 |
| 경계 구간(150~250 ms 실패) | 호스트 852 + 999회 | 모두 SAFE_STOP | 150 ms 이상 실패는 모두 정지한다 | 기준을 두지 않은 구간이라 합격 판정은 하지 않음 |

보고서에는 "89랩" 대신 조건별 랩 수, 총 제어 주기 수, 총 주입 횟수를 같이 적는다.
